# BLE 广播参数命令 (0x19) 完整规格文档

## 1. 概述

命令码 `0x19` 用于控制和查询 BLE 广播相关参数，支持以下功能：

| 参数类型 | 功能 | 状态 |
|---------|------|------|
| 0x01 | 广播信道控制 | ✅ 已实现 |
| 0x02 | 发射功率控制 | ✅ 已实现 |
| 0x03 | BLE 测试模式 | ✅ 已实现 |

---

## 2. 命令帧格式

### 2.1 基本帧结构

```
[帧头1] [帧头2] [地址] [命令码] [数据长度] [数据...] [校验和]
 57       AB      00      19        N        ...       XX
```

### 2.2 校验和计算

```
校验和 = (帧头1 + 帧头2 + 地址 + 命令码 + 数据长度 + 所有数据字节) & 0xFF
```

---

## 3. 功能详细说明

### 3.1 广播信道控制 (param_type = 0x01)

#### 功能描述
控制 BLE 广播使用的信道（CH37/CH38/CH39）

#### BLE 广播信道

| 信道 | 频率 | 位掩码 |
|------|------|--------|
| CH37 | 2402 MHz | bit0 = 0x01 |
| CH38 | 2426 MHz | bit1 = 0x02 |
| CH39 | 2480 MHz | bit2 = 0x04 |

#### 命令格式

| 子命令 | 功能 | 数据格式 |
|--------|------|----------|
| 0x00 | 获取当前信道映射 | `57 AB 00 19 02 00 01 [checksum]` |
| 0x01 | 设置信道映射 | `57 AB 00 19 03 01 01 [value] [checksum]` |

#### 信道映射值

| 值 | 含义 | 使用信道 |
|----|------|----------|
| 0x01 | 仅 CH37 | 2402 MHz |
| 0x02 | 仅 CH38 | 2426 MHz |
| 0x04 | 仅 CH39 | 2480 MHz |
| 0x03 | CH37 + CH38 | 2402, 2426 MHz |
| 0x05 | CH37 + CH39 | 2402, 2480 MHz |
| 0x06 | CH38 + CH39 | 2426, 2480 MHz |
| 0x07 | 全部信道 | 2402, 2426, 2480 MHz |

#### 响应格式

```
成功: 57 AB 00 D9 02 [param_type] [value] [checksum]
失败: 57 AB 00 D9 01 [error_code] [checksum]
```

#### 校验和公式

```
获取命令: 校验和 = (0x57 + 0xAB + 0x00 + 0x19 + 0x02 + 0x00 + 0x01) & 0xFF = 0x1E
设置命令: 校验和 = (0x57 + 0xAB + 0x00 + 0x19 + 0x03 + 0x01 + 0x01 + value) & 0xFF = (0x20 + value) & 0xFF
```

#### 完整命令码

| 功能 | 命令码 |
|------|--------|
| 获取信道映射 | `57 AB 00 19 02 00 01 1E` |
| 设置仅 CH37 | `57 AB 00 19 03 01 01 01 21` |
| 设置仅 CH38 | `57 AB 00 19 03 01 01 02 22` |
| 设置仅 CH39 | `57 AB 00 19 03 01 01 04 24` |
| 设置全部信道 | `57 AB 00 19 03 01 01 07 27` |

#### 限制条件
- 设备已连接时无法修改（返回错误 `STATUS_ERR_FRAME`）
- 值为 0 时自动改为 0x07（全部信道）

---

### 3.2 发射功率控制 (param_type = 0x02)

#### 功能描述
控制 BLE 发射功率，范围 -18 dBm 到 +7 dBm

#### 功率等级表

| 功率值 | 宏定义 | 十六进制 |
|--------|--------|----------|
| -18 dBm | LL_TX_POWEER_MINUS_18_DBM | 0x01 |
| -10 dBm | LL_TX_POWEER_MINUS_10_DBM | 0x03 |
| -5 dBm | LL_TX_POWEER_MINUS_5_DBM | 0x05 |
| -3 dBm | LL_TX_POWEER_MINUS_3_DBM | 0x07 |
| 0 dBm | LL_TX_POWEER_0_DBM | 0x09 |
| +1 dBm | LL_TX_POWEER_1_DBM | 0x0B |
| +2 dBm | LL_TX_POWEER_2_DBM | 0x0D |
| +3 dBm | LL_TX_POWEER_3_DBM | 0x11 |
| +4 dBm | LL_TX_POWEER_4_DBM | 0x15 |
| +5 dBm | LL_TX_POWEER_5_DBM | 0x1B |
| +6 dBm | LL_TX_POWEER_6_DBM | 0x25 |
| +7 dBm | LL_TX_POWEER_7_DBM | 0x3F |

#### 命令格式

| 子命令 | 功能 | 数据格式 |
|--------|------|----------|
| 0x00 | 获取当前功率 | `57 AB 00 19 02 00 02 [checksum]` |
| 0x01 | 设置功率 | `57 AB 00 19 03 01 02 [power] [checksum]` |

#### 校验和公式

```
获取命令: 校验和 = (0x57 + 0xAB + 0x00 + 0x19 + 0x02 + 0x00 + 0x02) & 0xFF = 0x1F
设置命令: 校验和 = (0x57 + 0xAB + 0x00 + 0x19 + 0x03 + 0x01 + 0x02 + power) & 0xFF = (0x21 + power) & 0xFF
```

#### 完整命令码

| 功能 | 命令码 |
|------|--------|
| 获取当前功率 | `57 AB 00 19 02 00 02 1F` |
| 设置 -18 dBm | `57 AB 00 19 03 01 02 01 22` |
| 设置 -10 dBm | `57 AB 00 19 03 01 02 03 24` |
| 设置 -5 dBm | `57 AB 00 19 03 01 02 05 26` |
| 设置 -3 dBm | `57 AB 00 19 03 01 02 07 28` |
| 设置 0 dBm | `57 AB 00 19 03 01 02 09 2A` |
| 设置 +1 dBm | `57 AB 00 19 03 01 02 0B 2C` |
| 设置 +2 dBm | `57 AB 00 19 03 01 02 0D 2E` |
| 设置 +3 dBm | `57 AB 00 19 03 01 02 11 32` |
| 设置 +4 dBm | `57 AB 00 19 03 01 02 15 36` |
| 设置 +5 dBm | `57 AB 00 19 03 01 02 1B 3C` |
| 设置 +6 dBm | `57 AB 00 19 03 01 02 25 46` |
| 设置 +7 dBm | `57 AB 00 19 03 01 02 3F 60` |

#### 响应格式

```
成功: 57 AB 00 D9 02 [param_type] [power_value] [checksum]
失败: 57 AB 00 D9 01 [error_code] [checksum]
```

#### 限制条件
- 设备已连接时无法修改（返回错误 `STATUS_ERR_FRAME`）
- 功率值必须是上述有效值之一，否则返回 `STATUS_ERR_PARAM`

### 3.3 BLE 测试模式 (param_type = 0x03)

#### 功能描述
启动 BLE 测试模式，在指定频率上持续发射射频信号，用于频谱分析

#### 测试频段

| 频段选择 | 频率 | 测试信道 | 说明 |
|----------|------|----------|------|
| 0 | 2402 MHz | 0 | 低频段 |
| 1 | 2440 MHz | 19 | 中频段 |
| 2 | 2480 MHz | 39 | 高频段 |

#### 频率计算公式

```
频率 = 2402 + 2 × 测试信道 (MHz)
```

#### 命令格式

| 子命令 | 功能 | 数据格式 |
|--------|------|----------|
| 0x00 | 启动测试模式 | `57 AB 00 19 04 00 03 [band] [power] [checksum]` |
| 0x01 | 停止测试模式 | `57 AB 00 19 02 01 03 [checksum]` |

#### 校验和公式（测试模式启动命令）

```
校验和 = (0x22 + band + power) & 0xFF
```

其中 `0x22` 是固定前缀 `57 AB 00 19 04 00 03` 的累加和取低8位。

## 5. 响应格式

### 5.1 信道控制响应 (param_type=0x01)

```
成功: 57 AB 00 D9 02 01 [channel_map] [checksum]
```

### 5.2 功率控制响应 (param_type=0x02)

```
成功: 57 AB 00 D9 02 02 [power_value] [checksum]
```

### 5.3 测试模式响应 (param_type=0x03)

**启动响应（4字节数据）：**
```
57 AB 00 D9 04 03 [status] [ret_code] [actual_power] [checksum]
```
- status: 0x01=成功, 0x02=回退成功
- ret_code: BLE API 返回值
- actual_power: 实际使用的功率值

**停止响应（3字节数据）：**
```
57 AB 00 D9 03 03 [status] [ret_code] [checksum]
```

## 7. 实现细节

### 7.1 代码位置

- **文件**: `APP/peripheral.c`
- **函数**: `Peripheral_BleAdvParamCommand()`
- **调用点**: `CH9329_DataParser()` 中处理 CMD_BLE_ADV_PARAM

### 7.2 关键变量

```c
// 当前发射功率（运行时跟踪）
static uint8_t g_current_tx_power = BLE_TX_POWER;  // 默认 0 dBm

// 测试模式标志
static uint8_t g_test_mode_active = 0;
```

### 7.3 测试模式实现流程

```
启动测试模式:
1. 检查设备是否已连接（已连接则拒绝）
2. 验证频段参数（0/1/2）
3. 验证功率参数（必须是有效值）
4. 停止广播
5. 设置指定功率
6. 调用 API_LE_TransmitterTestCmd() 启动测试
7. 设置 g_test_mode_active = 1

停止测试模式:
1. 调用 API_LE_TestEndCmd() 结束测试
2. 恢复默认功率
3. 重新启动广播
4. 清除 g_test_mode_active = 0
```

### 7.4 BLE 测试 API

```c
// BLE 5.x 测试命令
uint8_t test_params[4];
test_params[0] = tx_channel;      // TX 信道
test_params[1] = 255;             // 数据长度（最大）
test_params[2] = 4;               // 载荷类型：连续载波
test_params[3] = 1;               // PHY: LE 1M
ret = API_LE_TransmitterTestCmd(test_params, 0x2034);

// BLE 4.x 回退
if (ret != 0) {
    uint8_t test_params_v4[3];
    test_params_v4[0] = tx_channel;
    test_params_v4[1] = 37;       // BLE 4.x 最大长度
    test_params_v4[2] = 4;        // 连续载波
    ret = API_LE_TransmitterTestCmd(test_params_v4, 0x201E);
}
```

## 8. 使用注意事项

### 8.1 信道控制
- 修改信道映射前必须先断开连接
- 至少需要一个信道启用
- 修改后会自动重启广播

### 8.2 功率控制
- 修改功率前必须先断开连接
- 功率值必须是预定义的有效值
- 测试模式下功率设置可能不生效（硬件限制）

### 8.3 测试模式
- 测试模式下设备停止广播
- 停止测试后自动恢复广播
- 测试模式使用连续载波模式，频谱分析仪上显示为单频信号
- 高功率测试可能产生谐波杂波

## 9. 测试建议

### 9.1 基础测试顺序

1. **确认通信正常**
   ```
   57 AB 00 19 02 00 02 1F    # 获取当前功率
   ```

2. **测试各频段**
   ```
   57 AB 00 19 04 00 03 00 09 2B  # 2402MHz, 0dBm
   57 AB 00 19 04 00 03 01 09 2C  # 2440MHz, 0dBm
   57 AB 00 19 04 00 03 02 09 2D  # 2480MHz, 0dBm
   ```

3. **测试功率调节**
   ```
   57 AB 00 19 04 00 03 00 01 23  # 2402MHz, -18dBm
   57 AB 00 19 04 00 03 00 3F 61  # 2402MHz, +7dBm
   ```

4. **停止测试**
   ```
   57 AB 00 19 02 01 03 21
   ```

### 9.2 频谱分析仪设置建议

| 参数 | 建议值 |
|------|--------|
| 中心频率 | 2440 MHz |
| 频率跨度 | 80 MHz |
| 参考幅值 | -20 dBm |
| 网络跨度 | 100 kHz |
